# Spring AI Creative Hub

An AI-powered application built with Spring Boot that brings multiple generative AI features together in one place.

## Overview

Spring AI Creative Hub is a personal project focused on exploring and integrating Generative AI capabilities into a Spring Boot application.

The goal is to build a platform that makes everyday creative tasks easier through AI-powered generation.

## Planned Features

- **Recipe Generation** – Generate recipes based on ingredients or user preferences.
- **Message Generation** – Generate messages for different situations and purposes.
- **Photo Generation** – Generate images using AI based on text prompts.

*Features are currently under development.*

## Tech Stack

- Java
- Spring Boot
- Spring AI
- Maven

Additional technologies and integrations will be documented as the project evolves.

## Getting Started

### Prerequisites

- Java JDK
- Maven (or use the included Maven Wrapper)
- An IDE such as IntelliJ IDEA

### Clone the Repository

```bash
git clone https://github.com/Sougata2006/spring-ai-creative-hub.git
cd spring-ai-creative-hub
```

### Run the Application

Using Maven Wrapper:

**Windows:**
```bash
.\mvnw.cmd spring-boot:run
```

**Linux / macOS:**
```bash
./mvnw spring-boot:run
```

Application configuration and API credentials will be documented once the integrations are implemented.
